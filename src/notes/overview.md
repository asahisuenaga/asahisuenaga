<p>This document outlines the core architecture and user interface features of the Apple Notes clone built using vanilla JavaScript, HTML, and CSS.</p>

<h3>Core Interface</h3>
<ul>
  <li><strong>Responsive Sidebar:</strong> Includes a close sidebar button for maximum editing space.</li>
  <li><strong>Mobile Navigation:</strong> Utilizes a mobile view drawer for seamless phone and tablet use.</li>
  <li><strong>Data Persistence:</strong> Uses local storage save functionality to keep your data safe across sessions.</li>
</ul>

<h3>File Organization</h3>
<ul>
  <li><strong>Folder Creation:</strong> Organize your notes by creating custom folders.</li>
  <li><strong>Move to Folders:</strong> Organize clutter by shifting notes between different folders.</li>
  <li><strong>Delete Folders:</strong> Remove entire collections when they are no longer needed.</li>
  <li><strong>Deleted Folder:</strong> Safely stores removed items for a 30 days recovery period.</li>
</ul>
