<p>This document covers the note creation capabilities and text formatting tools available in the rich text editor.</p>

<h3>Note Management</h3>
<ul>
  <li><strong>Note Creation:</strong> Generate blank notes instantly within any selected folder.</li>
  <li><strong>Pin/Unpin:</strong> Keep important notes at the top of your list for quick access.</li>
</ul>

<h3>Typography Controls</h3>
<ul>
  <li><strong>Bold:</strong> Emphasize important text segments.</li>
  <li><strong>Italics:</strong> Slant text for style or emphasis.</li>
  <li><strong>Underline:</strong> Draw lines under key vocabulary or headers.</li>
  <li><strong>Strikethrough:</strong> Cross out completed tasks or old text.</li>
  <li><strong>Monospace:</strong> Format code snippets using fixed-width font.</li>
</ul>

<h3>Layout & Lists</h3>
<ul>
  <li><strong>Indent Right:</strong> Push text further into the page.</li>
  <li><strong>Indent Left:</strong> Pull text back toward the margin.</li>
  <li><strong>Checklist:</strong> Track interactive to-do lists easily.</li>
  <li><strong>Bullet List:</strong> Group related items together cleanly.</li>
  <li><strong>Number List:</strong> Order steps in sequential order.</li>
</ul>
